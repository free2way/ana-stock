# 选股流程产品收敛 · 第三阶段验收记录

日期：2026-07-23  
对应方案：[选股流程产品优化方案](stock-selection-workflow-ux-optimization-plan-2026-07-23-zh.md)

## 本阶段目标

让 A 股、美股在关键决策页共享同一条工作流，但始终保留独立的行情、候选和持仓上下文。

## 已实现

- 候选页在筛选总览后增加 `A 股 / 美股 / 全市场` 快捷切换，保持当前筛选参数并重新读取对应市场候选；
- 自选页增加市场上下文条：分别显示 A 股、美股的股票数、已确认行情数/可确认股票数、目标交易日，并可跳到对应市场明细；
- 自选页将“数据同步”和“执行过滤”收进默认折叠的维护/高级过滤区，避免日常决策路径被维护表单占据；
- 自选明细增加按市场的锚点，避免 A 股、美股明细混排；
- 持仓总览增加 A 股、美股快捷入口，分别显示持仓数和行情可用数，并跳转到各市场独立持仓区；
- 持仓原有的 CNY/USD 分市场汇总、行情缺失提示和风险处理队列全部保留。

## 数据口径

自选页的“行情已确认”使用每只自选股的同步日期与市场日历的最近可用收盘日比较：

- A 股按 A 股交易日判断；
- 美股按美股交易日判断；
- 关闭同步的股票不计入应确认数；
- 状态仅反映自选范围内的数据可用性，不冒充全市场数据健康结论。

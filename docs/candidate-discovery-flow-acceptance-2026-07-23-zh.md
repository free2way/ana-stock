# 发现候选页面筛选流程重构 · 验收记录

日期：2026-07-23

## 问题

原页面同时展示模板、市场、候选范围、共振、排序、阈值、基本面、评测、批量操作和结果。用户很难判断哪些是每天必须做的选择，哪些只是研究工具。

## 新流程

```text
1. 选择一个市场
2. 选择一种机会打法（模板）
3. 限定候选范围
4. 选择是否只看某类动作
5. 运行筛选，逐只核对触发、失效条件和风险
```

### 默认首屏

- 市场选择：A 股、美股、全市场；切换市场只更新筛选上下文，不自动执行筛选；
- 打法选择：以模板卡片解释趋势延续、回踩确认、防守观察等机会形态；
- 日常条件：候选范围、动作过滤和运行按钮；
- 结果：运行后直接查看候选与逐只详情。

### 按需展开

- 多模型共振、模型选择、排序、趋势/成交量阈值；
- 基本面、上市天数、快照命中、模型信号和执行标签；
- 模型解释、运行回执、评测、共振统计和质量画像；
- 保存策略、批量加入自选、同步和焦点池操作。

## 行为边界

- 模板、模型和评分只排序研究优先级；
- 用户仍必须在个股详情中确认入场触发、失效条件与风险；
- A 股与美股使用独立市场上下文；
- 没有更改任何模型、数据源、筛选规则默认值或后台 Job。

# 全局产品界面 Review 与重构记录

日期：2026-05-01

## 设计判断

这个应用已经从“量化研究网页”进入“盘后决策工作台”阶段。下一阶段的界面目标不是增加更多卡片，而是提高交易员每天重复使用时的扫描效率、路径稳定性和结果可信度。

## 当前主要问题

1. 信息层级偏重  
   多个页面同时展示导航、说明、模板、指标、结果和操作，首屏容易被入口和解释占满。

2. 页面风格不完全统一  
   主要页面都使用左侧导航，但卡片圆角、工具条、表格密度、按钮样式在不同路由里仍有差异。

3. 结果页密度还可以更专业  
   金融工作台更适合高密度、低装饰、强对齐的表格和状态标签，而不是偏营销式的大卡片。

4. A 股和美股模型边界需要更清楚  
   模型筛选页面此前已经能筛 A 股和美股，但用户需要更快知道“哪些模型适合哪个市场”。

5. 移动端需要保持可扫，而不是简单压缩桌面表格  
   手机、平板、电脑都会访问，移动端要优先保留关键动作和核心字段。

## 本轮已完成重构

1. 全局导航与壳层收敛  
   统一调整左侧导航、品牌区、激活态、滚动行为和移动端导航密度，让所有使用 `workspace_nav` 的页面更像同一个产品。

2. 全局控件密度统一  
   收紧卡片、按钮、输入框、工具条、表格、滚动条、chip 的尺寸和圆角，整体从“展示型页面”转向“操作型工作台”。

3. 模型筛选页重排  
   将 `/screeners` 改成更明确的选股控制台：先看当前市场/模板和筛选总览，再选择模型和组合，结果与后处理紧跟在后，评测和策略管理放到辅助区域。

4. 模型按市场分组  
   单模型下拉、模板卡片、多模型勾选区都分成：
   - 跨市场核心模型
   - A 股专用模型
   - 美股与全球质量模型

5. 单票详情页接入全局风格  
   `insights` 和 `symbols` 详情页接入统一紧凑样式，减少和主工作台之间的视觉断层。

6. 首页新闻模块减重  
   首页不再计算并展开新闻机会/风险明细，只保留新闻覆盖率、风险数量和跳转入口。新闻明细统一回到自选股页，新闻覆盖诊断放到任务中心。

7. 市场概览按交易时段重组  
   `/dashboard/market` 新增盘前准备、盘中脉冲、盘后复盘三种模式，直接复用后台预计算的三套市场快照，让市场页从“信息堆叠”变成“按交易场景行动”的工作区。

8. 高频页面二次压缩  
   首页、自选股、持仓、模型选股、社交信号、AI 问答的卡片、列表行、模板卡和顶部导航卡进一步收紧，减少“空大卡片”，让桌面和平板上的扫描密度更接近专业交易终端。

9. 美股热力图口径收敛  
   美股热力图默认切到资金流代理口径，并只把已补齐真实 sector 元数据的股票纳入板块资金流图。缺失 sector 的美股仍保留在连续强势、模型选股和个股详情里，但不再混入合成板块，避免误读为真实行业资金流。

10. 美股热力图可下钻  
    点击美股板块资金流色块后，不再跳到泛化总榜，而是在热力图页内展开该板块命中的股票明细，展示代码、名称、信号强度、模型分数和风险标签，保留同一市场上下文。

## 下一步建议

1. Dashboard 首页继续收敛  
   首页已经先移除了新闻明细，后续继续把历史日报、数据湖健康等深层模块保持在二级页，只在首页保留状态提示和入口。

2. 市场概览继续细化模式内容  
   已经完成三种模式入口，下一步可以让每种模式的榜单字段继续差异化，例如盘前更强调不能追，盘中更强调触发变化，盘后更强调明日计划。

3. 持仓页做“风险优先”视图  
   默认先展示需要处理的仓位，再展示完整持仓表；让减仓、退出、复核比普通展示更靠前。

4. 自选股页做“观察池分层”  
   将自选分成主攻、观察、风险、已失效四组，减少用户在长列表里寻找重点。

5. AI 问答页做金融 Copilot 工作台  
   预置提示词应按“持仓复盘、明日计划、单票分析、模型解释、风险排查”分组，而不是单纯模板堆叠。

## 验收标准

1. 用户进入任意核心页面，左侧导航、页面密度、卡片和表格风格一致。

2. `/screeners` 中可以一眼区分 A 股模型、美股模型和跨市场核心模型。

3. `/screeners` 首屏先服务筛选动作，而不是先展示大量说明入口。

4. 移动端不出现明显文字溢出、表格撑破和按钮过宽。

5. 后续新增页面优先复用 `WORKSPACE_COMPACT_STYLE` 与 `WORKSPACE_SIDEBAR_STYLE`，避免继续堆独立样式。

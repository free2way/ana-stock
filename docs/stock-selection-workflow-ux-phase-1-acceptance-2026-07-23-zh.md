# 选股流程产品收敛 · 第一阶段验收记录

日期：2026-07-23  
对应方案：[选股流程产品优化方案](stock-selection-workflow-ux-optimization-plan-2026-07-23-zh.md)

## 本阶段范围

完成低风险的信息架构收敛，不改变行情、模型、选股规则或自动任务。

## 已实现

- 全局侧栏改为五步日常路径：今日决策、市场判断、发现候选、自选与执行、持仓与复盘；
- 社交、AI、模型评测、任务中心、数据健康和设置保留在默认折叠的“研究与系统工具”中；访问其中页面时自动展开并高亮；
- 首页首屏新增“今日市场许可”、单一下一步按钮和四步流程卡；
- 首页将行情、模型、候选快照和日报状态收进折叠面板；失败/部分失败时自动展开；
- 首页增加不打断操作的首次使用说明；
- 自选页删除重复的首页/筛选/数据来源导航卡，改为“第 3 步 · 自选与执行”的行动说明；
- 模型筛选页改为“第 2 步 · 发现候选”，常用入口只保留返回工作台和自选，高级研究入口按需展开；
- 持仓页品牌和说明统一为“持仓与复盘”；
- 模型评测和 AI 日报相关页面使用对应的工具区高亮，而不是误高亮任务中心。

## 保留与兼容

- 原有 URL 未删除；
- 任务中心、数据健康、模型评测、Kronos 验证、社交信号、AI 问答和复盘心得仍可访问；
- A 股与美股的数据、模型和任务口径未改变；
- 本阶段没有变更任何数据源、后台 Job、模型参数或交易规则。
